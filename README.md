# Elevator Manager Tycoon 리디자인 제안 + 즉시 적용 결과

## 0) 프로젝트 포지셔닝 (전면 재정의)
**승강기 안전관리 체험형 운영 시뮬레이션**
- 플레이어 역할: 건물 관리자 + 안전관리 담당자 + 유지관리 총괄 매니저(혼합형)
- 핵심 메시지:
  1. 승강기는 지속 점검이 필요한 안전 인프라다.
  2. 사고 후 수습보다 사전 예방이 효율적이다.
  3. 운영 효율·이용자 편의·안전 확보를 동시에 관리해야 한다.

---

## 1) 현재 게임의 핵심 문제 진단
1. 시각 톤이 단순 박스형 프로토타입에 가까워 공공/심사 설득력이 약함.
2. 승강기 소재가 표면적이며, 전문 디테일(문 끼임/과부하/인터록/비상통화/정전 대응)이 약함.
3. 플레이 동기(중기 목표, 성취/칭호, 피크타임 대응)가 부족함.
4. UI 정보 구조가 KPI 중심 대시보드 형태가 아니라서 “완성형 시뮬레이션” 인상이 약함.
5. 라운드 피드백(놓친 안전 포인트)이 약해 교육성과 발표 포인트가 분산됨.

## 2) 전면 개선된 게임 컨셉 한 줄 정의
“예산·민원·혼잡 압박 속에서 승강기 안전을 선제적으로 관리해 검사 합격과 시민 신뢰를 동시에 달성하는 운영 시뮬레이션.”

## 3) 개선된 핵심 게임 루프
1. **수요/혼잡 발생**(시간대 + 이용자군)
2. **징후 관측**(먼지·정리·도어·제어·과부하·비상통화·인터록)
3. **우선순위 선택**(청소/정리/자체점검/예방교체/임시수리/민원대응/캠페인)
4. **연쇄 결과 반영**(민원 누적, 리스크 상승/하락, 만족도 변화)
5. **검사 준비도 축적**(평시 관리)
6. **정기검사 평가 + 라운드 리포트**(놓친 안전 포인트 제시)
7. **업적/칭호/다음 운영 전략 재설계**

## 4) 주요 시스템 상세 설계
- **예산 시스템**: 일일 수입 + 액션 비용 + 검사 페널티.
- **상태 연쇄 시스템**: 청결/정리 저하 → 센서·인터록/도어·제어 악화 → 민원·고장위험 상승.
- **업체 품질 차이**: 저가(속도↑, 품질↓) / 고급(예방효율↑, 재발↓).
- **민원 시스템**: 즉시 치명타 대신 누적 가중치로 장기 리스크 증가.
- **피크타임/이용자군**: 직장인·노약자·어린이동반·물류 유형별 혼잡/안전 민감도 반영.
- **특수 이벤트**: 문 끼임 위험, 과부하 감지 둔화, 층 정지 오차, 비상통화 응답 저하, 제동 저하, 인터록 경고.
- **검사 시스템**: 안전상태 + 청결 + 준비도 + 평판 - 민원/재발 페널티 = 점수.
- **라운드 리포트**: 결과 등급 + 놓친 포인트 + 다음 개선 근거.

## 5) 승강기 특화 이벤트 아이디어 (15+)
1. 문 끼임 위험 증가
2. 문 개폐 지연/불량
3. 층 정지 오차 경고
4. 과부하 감지 둔화
5. 버튼 반응 지연
6. 비상통화 응답 저하
7. 소음/진동 증가
8. 정전 시 비상전원 전환 점검
9. 화재 경보 시 승강기 사용 제한 안내
10. 침수/누수로 제어부 경고
11. 인터록 상태 불안정
12. 제동거리 증가 징후
13. 에스컬레이터 손잡이 속도 불일치
14. 에스컬레이터 역주행 방지 장치 경고
15. 유모차/캐리어 집중 시간대 혼잡 급증
16. 노약자 이용비율 급증으로 안전안내 수요 증가
17. 장기 임시수리 누적으로 반복 민원 폭증

## 6) UI 화면 구성안
- **상단 KPI 바**: 자금/안전도/만족도/고장률/점검률/날짜
- **좌측 실행 메뉴**: 운영조치/정비전략/이용자관리/시설확장(카드 그룹)
- **중앙 플레이필드**: 건물 단면 + 엘리베이터 이동 + 대기열 + 점검 캐릭터
- **우측 상세 패널**: 연식·혼잡도·징후·최근 점검일·고장위험
- **우측 업체 패널**: 유지보수 업체 선택
- **우측 로그 패널**: 민원/계절/긴급 이벤트
- **하단 리포트**: 최근 검사 결과/놓친 포인트/업적
- **팝업 알림**: 위험 이벤트/정기검사 도래

## 7) 그래픽/아트 스타일 가이드
- 키워드: **클린 · 신뢰 · 친근 · 현대적 공공 시뮬레이션**
- 색상 방향: 밝은 블루/민트 기반 + 경고(노랑) + 위험(주황/레드)
- 형태: 라운드 카드 + 얇은 외곽선 + 미세 그림자
- 애니메이션: 엘리베이터 이동, 대기열 변화, 말풍선 진동, 팝업 등장
- 금지: 과도한 유아풍, 과도한 기업툴풍(회색 단색 박스)

## 8) 게임 몰입도를 높이는 연출 요소
- 위험 징후 발생 시 우측 상단 토스트 팝업
- 민원 발생 시 말풍선 투명도 상승
- 혼잡 증가 시 대기열 바 상승
- 검사 직전 미션 배너 강조
- 업적 획득 시 칩 형태 노출

## 9) 라운드/스테이지 진행 구조
- **Stage 1 (MVP 현재)**: 2대 운영, 민원/예방정비/검사 루프 학습
- **Stage 2**: 피크타임 강화 + 점검 일정 캘린더
- **Stage 3**: 노후화/예산 압박 + 반복고장 패널티 확대
- **Stage 4**: 정전/화재/침수 대응
- **Stage 5**: 에스컬레이터 포함 복합 운영
- **Stage 6+**: 대형 복합건물 종합 안전관리

## 10) 교육성과 공공성을 살리는 장치
- “정답 텍스트” 대신 **행동-결과 피드백** 구조 사용
- 라운드 리포트에서 “놓친 안전 포인트” 자동 요약
- 예방정비의 비용 대비 효과를 수치로 체감
- 민원 데이터를 안전 신호로 재해석

## 11) 수상 가능성을 높이는 발표 포인트
- 왜 게임화?: 반복 훈련과 의사결정 학습에 최적
- 기존 자료 대비 장점: 수동 시청형이 아니라 능동 체험형
- 학습 성과: 예방 우선/징후 해석/우선순위 판단 습득
- 사회적 가치: 생활 안전 인식 향상 + 시설관리 역량 홍보
- 활용처: 안전주간 체험존, 청소년 진로교육, 공공기관 캠페인 부스

## 12) 실제 개발 우선순위 (필수/선택)
### 필수
1. KPI 대시보드 + 이벤트 팝업
2. 징후 연쇄 강화 + 검사 리포트 개선
3. 승강기 특화 이벤트군 확장
4. 단계/미션/업적 체계

### 선택
1. 아이소메트릭 아트 전환
2. 음향/보이스 가이드
3. 에스컬레이터 정밀 시뮬레이션
4. 데이터 분석 대시보드(교육기관용)

## 13) 리팩토링 로드맵
1. `simulation.js`를 도메인 모듈로 분해 (`riskEngine`, `inspectionEngine`, `eventEngine`)
2. `main.js` UI 렌더러와 상태 바인딩 분리 (`uiRenderer`, `uiActions`)
3. 설정 데이터 JSON화(이벤트/장비/스테이지/미션)
4. CSS 토큰화 + 컴포넌트화(BEM)
5. 장기적으로 Phaser 전환 시 시각 레이어만 교체 가능하게 유지

## 14) 바로 적용 가능한 개선안 (이번 반영)
- 상단 KPI 바, 좌측 기능 그룹 메뉴, 우측 상세 카드, 하단 라운드 리포트 추가
- 이벤트 팝업/업적 칩/미션 배너 추가
- 피크타임 + 이용자군 + 특화 징후 이벤트 + 에스컬레이터 도입(초기) 반영
- 검사 리포트에 놓친 안전 포인트 출력

## 15) 화면별 와이어프레임 설명 (텍스트)
- **Topbar**: `[자금][안전도][만족도][고장률][점검률][Day/계절]`
- **Left Menu**: `[운영조치] [정비전략] [이용자관리] [시설확장]`
- **Center**: `빌딩 단면 + 샤프트2 + 대기열바 + 이동카 + 말풍선`
- **Right**: `승강기 상세 카드 / 업체 카드 / 로그 카드`
- **Bottom**: `검사 결과 + 놓친 포인트 + 업적`
- **Popup**: `긴급 이벤트 토스트`
